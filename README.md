## 🌌 The Experience

**Aether** is not just an interface — it's a **living digital consciousness**.

Every thought becomes a glowing orb floating in an infinite nebula. Connect ideas, watch them evolve, explore your mind in 3D space. Built with obsessive attention to motion, depth, and emotional design.

### ✨ Key Features

- **Infinite 3D Nebula Canvas** with real-time physics
- **Emotional Orbs** — thoughts that react to your cursor and connections
- **Kinetic Typography** & cinematic scroll storytelling
- **Floating Glass UI** with advanced micro-interactions
- **Command Palette** (`⌘K`) with fuzzy search
- **Memory Constellations** — auto-generated idea clusters
- **Gesture-first Navigation** (mouse + touch)
- **60fps Optimized** 3D + 2D orchestration
- Fully responsive — premium mobile experience

## 🎥 Visual Identity

- **Typography**: Space Grotesk (Headings) + Inter (Body)

- **Style**: Glassmorphism + Volumetric Lighting + Subtle Noise
- **Motion Philosophy**: Organic, intentional, emotionally calibrated

## 🚀 Tech Stack

| Layer              | Technology                          | Purpose |
|--------------------|-------------------------------------|--------|
| Framework          | React 18 + TypeScript + Vite       | Performance & DX |
| 3D Engine          | Three.js + React Three Fiber + Drei | Nebula & Orbs |
| Animation          | GSAP + Framer Motion                | Cinematic motion |
| Scrolling          | Lenis                               | Butter smooth scroll |
| Styling            | Tailwind CSS + Advanced CSS         | Glassmorphism & Effects |
| State              | Zustand                             | Global UI state |
| Icons              | Lucide React + Custom SVG           | Premium iconography |
